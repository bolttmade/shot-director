5 Optional: run it for real with your own key

This page has no backend. If you have a Comfy API key with credits you can render the selected still and move yourself: your browser calls api.comfy.org directly. The key is kept in this tab's memory only (never saved, never put in the URL, never sent anywhere except api.comfy.org) and is gone when you close or reload the tab. Every run costs your credits, is submitted once and never retried, and needs an explicit confirmation. Not tested by anyone but the author, with a few cents of credits. Prefer the repo if you would rather not paste a key into a web page.

Source, honest status, credit log and process: github.com/bolttmade/shot-director. The full app (server, six-engine UI, timeline, reel export) runs locally with DEMO=1 ./run.sh. This static page is a client-side replay of its gallery plus a simplified in-browser previs; it does not run any generative model by itself.

All stills are AI-generated originals (no people, no photos); see examples/CREDITS.md. Partner-model outputs keep their providers' terms.
